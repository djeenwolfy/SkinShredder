# 🌐 Настройка и привязка прокси

Раздел **«Настройки» → «Прокси»** отвечает за сетевую изоляцию и стабильность работы ваших аккаунтов со Steam.

---

### ❓ Зачем нужны прокси?

У Steam очень жесткие ограничения на количество сетевых запросов:
* **Лимит запросов**: около 60–100 запросов в час с одного IP-адреса.
* **Ошибка 429 Too Many Requests**: если вы запустите проверку 10–20 аккаунтов со своего домашнего интернета без прокси, Steam мгновенно заблокирует ваш IP-адрес на 1–2 часа.
* **Блокировка сессий**: одновременный вход в 50 аккаунтов с одного IP вызывает подозрение службы безопасности Valve.

{% hint style="info" %}
* **1–2 аккаунта**: можно безопасно работать без прокси с домашнего интернета.
* **От 3 аккаунтов**: настоятельно рекомендуется использовать качественные серверные или мобильные/резидентские IPv4 прокси.
{% endhint %}

---

### 📝 Поддерживаемые форматы прокси

Программа автоматически распознаёт любые популярные форматы записи:
```text
ip:port:login:password
login:password@ip:port
http://login:password@ip:port
socks5://login:password@ip:port
ip:port (для прокси с привязкой по IP)
```

---

### ⚙️ Как добавить прокси?

1. Перейдите в **«Настройки» → «Прокси»**.
2. В большое текстовое поле вставьте список ваших прокси (по одному на строке).
3. Нажмите кнопку **«Сохранить и проверить»**.
4. Программа протестирует каждый прокси на доступность к серверам Steam и покажет задержку (пинг).

---

### 🔄 Автоматическая привязка к аккаунтам

Вам не нужно вручную прописывать прокси каждому боту:
* Программа использует механизм **равномерного распределения**:
  * Если у вас 20 аккаунтов и 5 прокси, на каждый IP будет назначено ровно по 4 аккаунта.
  * Если прокси выходит из строя, программа аккуратно перенаправит аккаунт на свободный рабочий адрес.
* Запросы между аккаунтами на одном IP всегда идут с безопасными интервалами, чтобы исключить подозрительную активность.
