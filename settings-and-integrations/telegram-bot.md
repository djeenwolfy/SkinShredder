# 📱 Telegram-бот уведомлений

Вкладка **«Настройки» → «Уведомления»** позволяет настроить личного Telegram-бота, который будет присылать отчёты о работе программы прямо на ваш смартфон.

---

### ⏱️ Шаг 1. Создание бота через @BotFather (2 минуты)

1. Откройте Telegram, найдите официального бота **@BotFather** (с синей галочкой) и нажмите **«Start»**.
2. Отправьте команду **`/newbot`**.
3. Придумайте имя для бота (например: `SkinShredder Отчёты`) и логин, который обязательно должен заканчиваться на `bot` (например: `my_cstrade_alert_bot`).
4. BotFather пришлёт длинный токен вида:
   ```text
   7123456789:AAHq_AbCdEfGhIjKlMnOpQrStUvWxYz
   ```
5. Скопируйте этот токен целиком.

---

### 💬 Шаг 2. Определение вашего чата (chat_id в 1 клик!)

Бот может писать только туда, где вы нажали ему старт:
1. Найдите созданного бота по логину в Telegram и нажмите кнопку **«Start»** (или отправьте `/start`).
2. В приложении SkinShredder вставьте токен в поле **«Токен бота»**.
3. Нажмите волшебную кнопку **«Найти chat_id»**!
4. Появится плашка с вашим именем — нажмите на неё. Программа сама подставит ваш цифровой идентификатор в поле «Чат»!

---

### 🧪 Шаг 3. Проверка и сохранение

1. Нажмите кнопку **«Проверить»**:
   * В ваш Telegram немедленно придёт сообщение: `SkinShredder на связи`.
2. Нажмите **«Сохранить»**.

---

### 🎛️ Шаг 4. Выбор типов уведомлений

После успешной проверки переключатели станут активными. Включите то, что вам интересно:

| Переключатель | Когда приходит уведомление |
| :--- | :--- |
| **Шаги цепочек** | По завершении каждого шага автоматизации (число отправленных вещей, выставленных лотов, найденных банов). |
| **Продажа в Steam** | Итоги массового выставления лотов с экрана продажи (сумма выручки, число предметов). |
| **Покупка в Steam** | Момент выставления ордеров и радостное сообщение, когда ордер полностью выкуплен! |
| **Отправка вещей** | Детальный отчёт по среднему дропу с фермы после сброса кейсов на хранилки. |
| **Отчёт за неделю** | Каждое утро понедельника в 10:00: финансовый итог недели (вложено, выведено, P&L, новые баны). Кнопка **«Прислать сейчас»** формирует отчёт за последние 7 дней немедленно! |
