# 📁 Папки и теги

Когда в парке десятки или сотни аккаунтов, ориентироваться по одним только логинам невозможно. В SkinShredder встроена гибкая система двухуровневой организации: **Папки** и **Теги**.

---

### ⚖️ В чём разница между папкой и тегом?

| Свойство | 📁 Папка (Место) | 🏷️ Тег (Свойство) |
| :--- | :--- | :--- |
| **Количество** | У аккаунта может быть **только одна** папка | У аккаунта может быть **сколько угодно** тегов |
| **Логика** | «Где лежит аккаунт» (физическое разделение) | «Какими свойствами обладает аккаунт» |
| **Примеры** | `Фарм`, `Хранилки`, `Трейд`, `Боты покупки` | `основной`, `прайм`, `без_баланса`, `u-1`, `2024` |
| **Вложенность** | Поддерживает структуру `Папка/Подпапка` | Плоский список меток |

{% hint style="warning" %}
**Обратите внимание!**
Перемещение аккаунта в новую папку **заменяет** прежнюю папку.
А добавление тега — **прикрепляется** к уже имеющимся тегам аккаунта.
{% endhint %}

---

### 📂 Работа с папками

* **Фильтрация**: Вверху таблицы «Аккаунты» расположен ряд кнопок с вашими папками. Нажатие на папку мгновенно отфильтрует таблицу.
* **Вложенность**: Если создать папку `Фарм/Группа 1` и `Фарм/Группа 2`, выбор родительской папки `Фарм` покажет аккаунты из всех вложенных подпапок.
* **Перемещение**:
  1. Выделите нужные аккаунты галочками.
  2. Нажмите **«Ещё» → «Папка»**.
  3. Выберите существующую папку или создайте новую → **«Применить»**.

---

### 🏷️ Работа с тегами

Теги позволяют гибко группировать аккаунты из разных папок для разовых действий или автоматизации в цепочках.
* **Назначение тегов**:
  1. Отметьте нужные аккаунты.
  2. Нажмите **«Ещё» → «Теги»**.
  3. Введите тег и нажмите Enter.
* **Фильтрация по тегам**: В строке фильтров нажмите на нужный тег, чтобы скрыть всё лишнее.
